Game Basics:
slot(where land is staked)
land (where miners are staked/send to mine)
equipments/boosters (it will be equipped with miners to boost the mining)
Currency - one NFT and another FT( FT is tokens that will be mined and NFT is rare drop that can be get with rng during the mining)

currency configurations should be able to done by admin account like which nft template to be considered currency and which ft contract address to be considered ft

Game mechanics:
Player will signup/signin with his wax wallet( signup url can include referral link)
player will get one slot unlocked by default
player can put any lands on that slot.
and to unlock more slot they need to activate/burn the slot nft. each index slot will have its own nft, for example if user wants to unlock 2nd slot he needs to buy the nft templated that will unlock that slot. meaning that template cant unlock another slot. and another thing user cant unlock 3 slot if he has not unlocked 1st and 2nd slot, and same for other. By default there will be 5 slots per account at the initial. In future there might be more slots that needs nfts to add on that account and again that slot needs to be unlocked with nfts. and these nfts are to be burned once activated.

And these nfts configurations should be done by admin
